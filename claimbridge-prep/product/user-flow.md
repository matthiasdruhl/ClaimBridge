# User flow

1. Landing: 'Understand a medical claim' and 'Try synthetic demo'. Six-file fixture list explains that one document is added later. Real-record uploads are outside this demonstration.
2. Upload initial five PDFs. Each receives a type, page count, extraction status and replace/remove control. Show validation errors per file.
3. Processing: extracting -> matching claims -> reviewing plan -> checking sources. Show actual job stages; do not fake live progress for replay.
4. Workspace opens with the $4,200 disputed bill, plan payment $0, allowed amount 'Not determined' and notice that the facility claim is separate.
5. Highlight 'The records disagree about where anesthesia happened.' View POS/denial alongside authorization and facility EOB. No verdict yet.
6. Answer location question; attach D06. A 'user reported' chip changes to 'supported by added document' only after verification. Ask receipt date separately.
7. Refresh analysis and action plan. Show the new evidence and remaining missing recognized amount. Do not turn 'requested correction' into 'corrected'.
8. Open appeal draft, review attachments and factual uncertainty. Copy/download only; do not send.
9. If a question is unanswered or a PDF is unreadable, retain partial results and show the exact missing item. Reset returns to initial fixtures.
